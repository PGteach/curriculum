Three technologies at work

Open any web page and you are seeing three technologies at work together. HTML builds the structure — the headings, paragraphs and links, like the frame of a building. CSS adds the appearance — colours, layout and fonts, like a building’s interior. JavaScript adds behavior — search boxes that respond, buttons that count, screens that update.

Today’s question. How do HTML, CSS, and JavaScript work together to build a web page, and what makes a modern frontend meaningful, adaptable, and efficient to build?

Part 3 · Responsive design

Responsive design

A design concept in which the layout is automatically adjusted to different screen sizes such as PCs, smartphones and tablets. One page, easy to view on any device.

التصميم المتجاوب: التخطيط بيتظبط تلقائيًا حسب حجم الشاشة.

ScreenThe same three boxes
Phoneone column: the boxes stack
Tablettwo side by side, the third below
PCall three in one row

Mobile-first: many people use the web on their phones, so developers think about small screens from the very start of the design.

Prepared by: Mr. Eissa Islam

Frameworks

Framework

A structure that provides common functions and components in advance, to make web application development more efficient — you do not write everything from scratch.

إطار العمل: وظايف ومكونات جاهزة عشان التطوير يبقى أكفأ.

NameWhat to know
ReactFrom Meta. Updates only part of the screen; a JavaScript library for interfaces built from reusable components.
VueA simple structure; build step by step from small features.
Next.jsBuilt on React; adds routing and faster ways to show pages.
Looks right, but is falseWhy
Semantic HTML necessarily makes a page display faster.Its benefits are accessibility and SEO.
A framework is a language for defining the structure of a page.That is HTML.
Responsive design means the page works only on computers.It adapts to every screen.

TagMakes
<h1>a big heading

Specifying ranges: div and span

<div class="card"> <h3>Robot day</h3> <p>Thursday, 2 pm</p> </div> <p>Bring your <span class="hot">own laptop</span>.</p>
TagMarks
<div>a block: a box that holds several elements
<span>a range inside a line of text

Input fields and buttons

<input type="text" placeholder="Your name"> <button>Sign up</button>

placeholder shows a grey hint until the user types. <input> has no closing tag; <button> does.
