1-1 · Exam-style question · 6 marks

Analyse how the spread of cloud computing (from the 2010s onward) has changed the way information technology is used. Refer to: large-scale data analysis, AI, and "IT as a service".

p.10 — Exam-style question [6]

Plan first. Write your points here, then check them against the marking points below. Each point is about one mark.

The marking points

  1. Cloud computing spread from the 2010s onward.
  2. It made large-scale data analysis possible, because storage and processing power can be rented rather than owned.
  3. That data and power in turn support AI.
  4. IT became something delivered as a service over the Internet, rather than hardware each organisation buys and maintains.
  5. Effect: smaller organisations and individuals can now use computing power that previously needed a large investment.

1-2 · Exam-style question · 6 marks

Analyse the relationship between AI, machine learning, deep learning and generative AI, with an example of each.

p.16 — Exam-style question [6]

Plan first. Write your points here, then check them against the marking points below. Each point is about one mark.

The marking points

  1. AI is the broad field: technologies that perform intelligent human behaviour on a computer. Example: speech recognition.
  2. Machine learning sits inside AI: it learns patterns from data to make predictions and judgments. Example: a spam filter.
  3. Deep learning sits inside machine learning: it uses neural networks and large-scale data. Example: image analysis for autonomous driving.
  4. Generative AI is built on deep learning and generates new data. Example: ChatGPT.
  5. The four are nested categories, each more specialised than the one before, not four separate technologies.

1-3 · Exam-style question · 6 marks

Analyse why AI is well suited to some tasks but requires caution in others.

p.22 — Exam-style question [6]

Plan first. Write your points here, then check them against the marking points below. Each point is about one mark.

The marking points

  1. AI is good at finding and classifying patterns in complex data such as images and text.
  2. It is good at recognition and generation of images, audio and text.
  3. It is good at probabilistic reasoning and prediction from data.
  4. Caution: ethical judgments may carry discrimination or prejudice.
  5. Caution: anything involving personal data raises privacy questions.
  6. Caution: final decision-making — someone has to be responsible for the result.

1-4 · Ethical Issues with AI

Remember. If training data is biased, an AI can reproduce that bias; using AI responsibly means checking for bias, being able to explain decisions, and knowing who is accountable — guided by fairness, transparency, privacy protection, and accountability.

لو بيانات التدريب متحيزة، الذكاء الاصطناعي هيكرر التحيز. الاستخدام المسؤول: نفحص التحيز، ونقدر نفسّر القرار، ونعرف مين المسؤول — بالعدالة والشفافية وحماية الخصوصية والمساءلة.

Exam traps

StatementT / FWhy
Algorithmic bias is caused by the AI's processing speed.FalseIt comes from bias in the training data.
If an AI's process is opaque, there is no problem as long as the result is correct.FalseAn opaque result cannot be checked.
Who is responsible when an AI is wrong has already been clearly decided.FalseNo clear standard exists yet among developers, users and operators.
Bias in training data can cause discriminatory bias in AI judgments.TrueThat is exactly algorithmic bias.

1-4 · Exam-style question · 6 marks

Analyze how algorithmic bias can arise in an AI system, and how it can be reduced, using the principles of AI ethics.

p.30 — Exam-style question [6]

Plan first. Write your points here, then check them against the marking points below. Each point is about one mark.

The marking points

  1. Cause: the AI learns from training data
  2. Biased or insufficient data is reproduced in its judgments, with an example
  3. A second source: past discrimination in data, or proxy variable / variable choice
  4. Reduction through fairness: check data, test results across groups
  5. Reduction through transparency: show the decision process / XAI
  6. Links the measures back to the cause, so the answer is an analysis, not a list
Prepared by: Mr. Eissa Islam
