2-1 · Exam traps

True or false?

  • HTTPS exchanges all of its data using public-key cryptography. — false: Public-key only shares the key; common-key moves the data.
  • Setting two passwords is multi-factor authentication. — false: Both are knowledge: one factor twice.
  • A digital certificate verifies that the communication partner is genuine. — true: That is its job.
  • A digital signature keeps the content from being read by third parties. — false: That is encryption; a signature detects tampering.

Decide first, then tap.

قرّر الأول صح ولا غلط، وبعدين دوس. الجمل دي من الكتاب وكتاب التقييمات.

2-1 · Exam-style question · 6 marks

Plan it, then check the points

Explain why HTTPS uses public-key cryptography to share the key and common-key cryptography to exchange the data.

  • Point 1 — Both sides need the same common key, and sharing it openly is not safe
  • Point 2 — Public-key cryptography shares the key safely — public key locks, private key unlocks
  • Point 3 — Public-key cryptography is slow for large amounts of data
  • Point 4 — Common-key cryptography exchanges large amounts of data quickly
  • Point 5 — So public-key is used only to share the key, common-key for the data
  • Point 6 — Result: security and speed together

Source: p.37 — Exam-style question [6]. Each point is about one mark.

2-2 · Exam traps

True or false?

  • A VPN automatically deletes files infected with viruses. — false: That is antivirus software on the endpoints.
  • A DMZ is mainly there to make communication faster. — false: It stops an attack on a public server reaching the internal network.
  • Under zero trust, access from inside the network needs no checking. — false: Every access is verified, inside or outside.
  • In defense in depth, if one measure is breached the next can still protect the system. — true: That is the whole point.

Decide first, then tap.

قرّر الأول صح ولا غلط، وبعدين دوس. الجمل دي من الكتاب وكتاب التقييمات.

2-2 · Exam-style question · 6 marks

Plan it, then check the points

Explain why layering several security measures (defense in depth) protects an organization better than relying on a firewall alone. Refer to what happens if one measure is breached.

  • Point 1 — A firewall alone is one barrier
  • Point 2 — If that one barrier is breached, everything inside is exposed
  • Point 3 — Defense in depth layers several measures
  • Point 4 — Names at least two layers or measures, e.g. VPN, DMZ, endpoints
  • Point 5 — If one is breached, the next still protects the system
  • Point 6 — Conclusion: one breach is much less likely to expose the whole network

Source: p.45 — Exam-style question [6]. Each point is about one mark.

2-3 · Exam traps

True or false?

  • Detection → Eradication → Containment → Recovery is the right order. — false: Containment comes before eradication.
  • The size of a risk can be judged by impact alone. — false: Risk = impact × likelihood.
  • All risks must be addressed at the same time. — false: Set priorities: the biggest first.
  • A software update that adds features is a security incident. — false: Nothing was damaged.

Decide first, then tap.

قرّر الأول صح ولا غلط، وبعدين دوس. الجمل دي من الكتاب وكتاب التقييمات.

2-3 · Exam-style question · 6 marks

Plan it, then check the points

Explain why the six stages of incident response must be carried out in order, using recovery and eradication as an example. Refer to what happens if the cause is not removed.

  • Point 1 — Containment first stops the damage spreading
  • Point 2 — Eradication removes the cause, e.g. the malware
  • Point 3 — Recovery returns systems to normal only after that
  • Point 4 — If recovery comes before eradication, the cause is still there
  • Point 5 — So the same incident can happen again
  • Point 6 — Conclusion: order keeps damage small / may need to step back

Source: p.51 — Exam-style question [6]. Each point is about one mark.

Mixed questions

  • Which cryptography shares the key in HTTPS? — Public-key cryptography.
  • A password and a fingerprint: how many factors? — Two: knowledge and biometric.
  • Which technology proves a shopping site is genuine? — A digital certificate.
  • Where does a public web server belong? — In the DMZ.
  • Which layer is antivirus software and an updated OS? — Endpoints.
  • Ransomware is spreading. What comes first: contain or eradicate? — Contain: stop it spreading first.
  • Impact 3, likelihood 2: the risk size? — 6.
  • Stage 6 has a second name. What is it? — Lessons learned and improvement.
