Your device asks, a server answers

When you click a link or press “search”, your device does not hold the whole website — it asks a distant computer for it. Your browser is the client that makes the request; a server somewhere answers with a response. This exchange, governed by shared rules called protocols, is how every web application communicates.

Today’s question. How do the client and server communicate to make a web application work, and what rules and messages do they use?

إزاي العميل والخادم بيتواصلوا عشان يشغّلوا تطبيق الويب، وإيه القواعد والرسائل اللي بيستخدموها؟

TermMeaning

Part 2 · HTTP and HTTPS

HTTP (HyperText Transfer Protocol)

A communication protocol for exchanging data between clients (browsers and apps) and servers.

بروتوكول بيستخدم لتبادل الرسائل بين عميل وخادم على الويب.

HTTPS (HTTP Secure)

HTTP with TLS encryption added. The content is encrypted, so the risk of it being read by third parties is reduced. Addresses that begin with https:// use it.

استخدام HTTP عبر اتصال TLS آمن: بيحمي سرية الاتصال وسلامته وبيتحقق من الخادم.

Pause and think. Why should a login page use HTTPS rather than plain HTTP?

Part 3 · The request carries an HTTP method

MethodRoleExamples
GETRetrieve data from the serverDisplaying a web page, retrieving search results
POSTSend data to the serverSending login information, submitting a form

The response carries a status code

Status codeMeaning
200Success — the request was processed successfully
404Page not found — the requested address does not exist
500Server error — a problem occurred on the server side (on its own it does not say the detailed cause)

One request, one matching response

StepWhereWhat happens
①ClientYou search cats: the browser sends a GET request
②ServerReceives the request and processes it
③ClientThe response arrives: status code 200 and the results page
④ClientYou log in: a POST request, over HTTPS, so the password is encrypted
⑤ServerReceives the login data and checks it
⑥ClientStatus code 200, and your account page comes back

Part 4 · API and JSON

API (Application Programming Interface)

A system for exchanging data between different pieces of software. In web applications, the frontend often sends requests to the backend through an API and receives data.

مجموعة قواعد واضحة بتسمح لبرنامج يطلب بيانات أو وظائف من برنامج تاني.

JSON (JavaScript Object Notation)

A data format that is easy for humans to read and for computers to process. It is made of keys and their values.

صيغة نصية شائعة لتمثيل وتبادل البيانات المهيكلة.

{ "city": "Cairo", "temperature": 31 }

Key "city" has the value "Cairo"; key "temperature" has the value 31.

Looks right, but is falseWhy
Status code 500 means the request was processed successfully.500 is a server error; success is 200.
An API adjusts the appearance of web pages.It exchanges data between software.
JSON encrypts the connection.JSON is a data format; HTTPS encrypts.

A flowchart draws a program’s steps in order. Arrows show which step comes next.

كل شكل بيتحول لسطر: المستطيل = let أو حساب، المعين = if، سهم Yes = جوّه if، سهم No = else، متوازي الأضلاع = console.log.

Your turn · write the code

let a = 8; let b = 5; if (a > b) { console.log(a); } else { console.log(b); }

It shows 8. If b were 11, it would show 11.

Rules of a good flowchart
One Start and one End, both ovals
A diamond has two exits: Yes and No
A calculation goes in a rectangle, not a diamond
The arrows show the order the steps run in
