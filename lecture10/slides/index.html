This happens every time you click

Your device asks, a server answers

When you click a link or press “search”, your device does not hold the whole website — it asks a distant computer for it. Your browser is the client that makes the request; a server somewhere answers with a response. Shared rules called protocols govern the exchange.

Hands up: you see a page that says 404. Is the Internet broken, is the server broken — or something else? Remember your answer.

لما بتدوس على لينك أو بتبدأ بحث، المتصفح غالبًا بيطلب البيانات اللي محتاجها من خدمة على خادم عبر الشبكة. المتصفح هنا عميل (client) بيبعت طلب، والخادم (server) بيرجّع استجابة، وبروتوكولات زي HTTP بتحدد قواعد التبادل ده.

Part 2 · HTTP and HTTPS

A postcard or a sealed envelope

HTTP (HyperText Transfer Protocol) — a communication protocol for exchanging data between clients and servers.
HTTPS (HTTP Secure) — HTTP with TLS encryption added. The content is encrypted, so the risk of it being read by others is reduced.

Addresses that begin with https:// use HTTPS. The Arabic book adds: TLS also stops the content being changed on the way, and checks it is the real server.

✉HTTP
a postcard: anyone on the way can read it→readable
🔒HTTPS
a sealed envelope: TLS encrypts it→encrypted

Same message, but only one is sealed.نفس الرسالة، بس واحدة بس متقفلة.

HTTP: بروتوكول بيستخدم لتبادل الرسائل بين عميل وخادم على الويب. HTTPS: استخدام HTTP عبر اتصال TLS آمن؛ بيحمي سرية الاتصال وسلامته، وبيتحقق من الخادم، فالمتجسس ميقدرش يقرا المحتوى أو يعدّله بسهولة. والمواقع اللي عناوينها بتبدأ بـ https:// بتستخدم HTTPS.

Part 3 · The request: an HTTP method

GET or POST?

Every request carries an HTTP method: what kind of operation is wanted.

MethodRoleExamples
GETRetrieve data from the serverDisplaying a web page, retrieving search results
POSTSend data to the serverSending login information, submitting a form
OperationMethod
a · Displaying a web pageGET
b · Submitting an ID and password in a login formPOST
c · Displaying search resultsGET
d · Submitting a contact formPOST

كل طلب فيه طريقة طلب HTTP بتوضح نوع العملية المطلوبة. GET بيستخدم عادةً لطلب مورد أو بيانات من الخادم، زي عرض صفحة أو نتايج بحث. POST بيستخدم عادةً لإرسال بيانات يعالجها الخادم، زي تسجيل الدخول أو إرسال نموذج.

3 · The response: a status code

Three numbers to know

Every response carries a status code: a number that reports the result.

Status codeMeaning
200Success — the request was processed successfully
404Page not found — the requested address does not exist
500Server error — a problem occurred on the server side

The Arabic book adds: a 500 alone does not say what went wrong — only that it was on the server.

Part 4 · API (Application Programming Interface)

Programs asking programs

API — a system for exchanging data between different pieces of software.

In web applications, the frontend often sends requests to the backend through an API and receives data back. That data is often written in JSON (JavaScript Object Notation): easy for people to read, and for computers to process.

{ "city": "Cairo", "temperature": 31 }
  • Name one key and its value. — key "city", value "Cairo" (or key "temperature", value 31).

واجهة برمجة التطبيقات (API): مجموعة قواعد واضحة بتسمح لبرنامج يطلب بيانات أو وظائف من برنامج تاني. وممكن ترجّع بيانات بصيغة JSON، وهي صيغة نصية لتمثيل البيانات المهيكلة. اقرا البيانات دي وحدد مفتاح (key) وقيمته (value).

Exam warning

True or false?

  • Status code 500 means the request was processed successfully. — false: 500 is a server error; success is 200.
  • An API is a technology for adjusting the appearance of web pages. — false: it exchanges data between software.
  • JSON is used to encrypt the connection. — false: JSON is a data format; HTTPS encrypts.
  • To send login data, POST is the right method. — true.

خلّي بالك: 500 مش نجاح — ده خطأ في الخادم. الـ API مش لشكل الصفحة. JSON صيغة بيانات مش تشفير. وبيانات الدخول بتتبعت بـ POST.

5 · Watch out

Rules of a good flowchart

  • A diamond has only one way out. — false: two, labelled Yes and No.
  • A flowchart begins at Start and finishes at End. — true: ovals.
  • A calculation such as total = price * 3 goes in a diamond. — false: a calculation is a process, a rectangle.
  • The arrows show the order the steps run in. — true.

خلّي بالك: المعين ليه مخرجين Yes و No. بنبدأ بـ Start ونخلص بـ End. الحساب في مستطيل مش معين. والأسهم بتوضح الترتيب.

Remember these

What we learned

  • The client requests, the server responds.
  • HTTP carries the messages; HTTPS adds TLS encryption.
  • GET retrieves, POST sends. Status codes: 200 success, 404 not found, 500 server error.
  • An API lets programs exchange data, often as JSON.
  • A flowchart: oval start/end, rectangle process, diamond decision (if), parallelogram output.

العميل بيطلب والخادم بيرد • HTTP بينقل و HTTPS بيشفّر • GET بيجيب و POST بيبعت • 200 و 404 و 500 • API و JSON • والمخطط الانسيابي: بيضاوي، مستطيل، معين، متوازي أضلاع.
