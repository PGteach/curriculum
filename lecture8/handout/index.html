Going through an array — for…of

Student Booklet

Introduction

You already know two things: an array holds many values, and a for loop repeats. This session joins them with one tidy tool — for…of — which walks through an array and hands you each value in turn.

إنت عارف حاجتين: المصفوفة بتشيل كذا قيمة، وحلقة for بتكرّر. النهاردة بنجمعهم بأداة واحدة مرتبة — for…of — بتمشي على المصفوفة وتديك كل قيمة بالدور.

1 · Two reminders

An array numbers its drawers from 0. A normal for loop keeps a counter i.

let fruits = ["apple", "banana", "mango"]; // fruits[0] = "apple" fruits[1] = "banana" fruits[2] = "mango" // fruits.length = 3
1

Values

apple, banana, mango — stored under one name

2

Numbered from 0

the first value is fruits[0]

3

Length

.length is how many — here 3

المصفوفة بتبدأ الترقيم من صفر، و .length هو عدد القيم.

Prepared by: Mr. Eissa Islam

2 · The for…of loop

Instead of a counter, for…of gives you the value directly, one per round:

let fruits = ["apple", "banana", "mango"]; for (let fruit of fruits) { console.log(fruit); }

prints → apple, then banana, then mango

PartWhat it means
fruita name you choose — holds one value each round
ofthe keyword meaning “take from”
fruitsthe array you are going through

الاسم اللي بعد let إنت بتختاره، وبعد of بتحط المصفوفة.

The same job, the long way

With a normal for you must manage the counter yourself: for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }. Use for…of when you only need the values.

Session Summary

An array holds many values, numbered from 0.

for…of walks the array and gives you each value in turn.

Read for (let fruit of fruits) as “for each fruit in fruits”.

No counter and no .length — print the value directly.

Need the drawer number too? Use the normal for with i.
