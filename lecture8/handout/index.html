Introduction · a box of sweets

Imagine a box of sweets. You take out one sweet, eat it, then take the next one — until the box is empty. Today you learn for…of, a loop that does exactly this with an array: it gives you one value at a time, until there are no values left.

1 · Remember: an array is a row of drawers

let fruits = ["apple", "banana", "mango"];
"apple"[0]
"banana"[1]
"mango"[2]

The drawer numbers start at 0: fruits[0] is "apple". fruits.length is 3 — the number of values.

2 · The for…of loop

let fruits = ["apple", "banana", "mango"]; for (let fruit of fruits) { console.log(fruit); }

Read it as: “for each fruit of fruits, print it.”

اقراها: «لكل fruit من fruits، اطبعها».

WordWhat it means
fruita name you choose — it holds one value each time
ofmeans “take from”
fruitsthe array you go through

Tip: name it the singular of the array: pets → pet, names → name.

4 · The old way and the easy way

Both print every fruit. The normal for needs three things right; for…of needs none of them.

Normal for (with a counter)

for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }

start at 0 · stop at the end · open the drawer fruits[i]

for…of

for (let fruit of fruits) { console.log(fruit); }

no counter · no .length · the value is ready

الاتنين بيطبعوا كل الفواكه. بس for…of مفيهاش عدّاد ولا .length خالص

Watch out: the most common mistake

In for (let fruit of fruits), fruit is already the value (like "apple"), not a drawer number. So write console.log(fruit) — not console.log(fruits[fruit]).

المتغير هو القيمة نفسها، مش رقم الدُرج. اطبعه على طول.

6 · if and else

Every morning you decide: if it is raining, take an umbrella. Otherwise, take sunglasses. A program decides the same way:

if (weather == "rain") { console.log("Take an umbrella"); } else { console.log("Take sunglasses"); }
PartWhat it does
( … )the conditional expression: a question whose answer is true or false
if { }runs only when the answer is true
else { }runs when the answer is false

لو بتمطر خُد شمسية، غير كده خُد نضارة شمس. ولاحظ إن «يساوي» بتتكتب == (علامتين).

8 · More than two choices: if, else if, else

if (score >= 90) { console.log("Excellent!"); } else if (score >= 50) { console.log("You passed"); } else { console.log("Try again"); }

The computer reads from the top down (sequential execution) and runs the first branch that is true. The rest are skipped.

scorescore >= 90?score >= 50?It prints
95truenot askedExcellent!
70falsetrueYou passed
30falsefalseTry again

أول شرط يطلع true هو اللي بيتنفذ، والباقي بيتساب.

Watch out: the order matters

If you write score >= 50 first, then a score of 95 prints “You passed”: 95 >= 50 is already true, so the computer stops there and never checks 90. Put the hardest (biggest) condition first.

حط الشرط الأصعب (الأكبر) الأول، لأن الكمبيوتر بيقف عند أول شرط true.

11 · A loop and a decision

The for…of takes one value; the if decides for that value. Then the next one.

let marks = [80, 40, 65]; for (let mark of marks) { if (mark >= 50) { console.log(mark + " pass"); } else { console.log(mark + " fail"); } }

Session Summary

for…of gives you each value of an array, one at a time, then stops.

if (…) runs only when the condition is true; else runs when it is false.

else if is checked top down: the first true branch runs — put the hardest condition first.

You can do math inside a condition, and put an if inside an if.

A loop with an if inside decides for every value.
