Part 3 · Write it yourself

الجزء التالت — اكتبه بنفسك

6Rewrite this normal for loop as a for…of loop. It must print the same thing.

اكتب حلقة for العادية دي بطريقة for…of. لازم تطبع نفس الحاجة.

let cities = ["Cairo", "Giza", "Aswan"]; for (let i = 0; i < cities.length; i++) { console.log(cities[i]); }

let friends = ["Ali", "Mona", "Omar"];
