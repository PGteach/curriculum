JavaScript · Qureo Chapter 28

Going through an array — for…of

By the end you can print every value in an array with one short, tidy loop.

في آخر الحصة هتعرف تطبع كل قيمة في المصفوفة بحلقة واحدة قصيرة ومرتبة.

1 · Remember first

An array is a box with many drawers

One name, many values inside, each in its own drawer.

let fruits = ["apple", "banana", "mango"];

The drawers are numbered from 0: apple is fruits[0], banana is fruits[1], mango is fruits[2].

المصفوفة اسم واحد جواه كذا قيمة، كل قيمة في درج. الترقيم بيبدأ من صفر: fruits[0] هي أول قيمة.

2 · Remember first

A for loop repeats, and counts as it goes

for (let i = 0; i < 3; i++) { console.log(i); }

prints 0, then 1, then 2

It keeps a counter i, checks a condition, and adds 1 each round.

حلقة for بتكرّر، وبتعدّ وهي ماشية: بتمسك عدّاد i، وبتزوّده واحد كل لفة.

3 · The problem

Printing every fruit — the long way

To use the counter as a drawer number, you must get three things right.

let fruits = ["apple", "banana", "mango"]; for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }

You wrote i four times, and you had to remember fruits.length and fruits[i]. Easy to get wrong.

لازم تكتب العدّاد صح، وتفتكر .length و fruits[i]. سهل تغلط.

4 · The easy way

Meet for…of

It hands you each value, one at a time. No counter, no drawer numbers.

let fruits = ["apple", "banana", "mango"]; for (let fruit of fruits) { console.log(fruit); }

prints apple, then banana, then mango

بتديك كل قيمة لوحدها، من غير عدّاد ولا أرقام دُرج. اقرأها: "لكل fruit جوّه fruits".

5 · Side by side

Same result, less to write

Normal for

for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }
  • counter i
  • needs .length
  • needs fruits[i]

for…of

for (let fruit of fruits) { console.log(fruit); }
  • no counter
  • no .length
  • the value is ready

نفس النتيجة بالظبط، بس كتابة أقل وغلط أقل.

6 · Read it part by part

The three words that matter

for (let fruit of fruits) { … }
PartWhat it is
fruita name you choose — one value each round
ofthe keyword that means "take from"
fruitsthe array you are going through

الاسم اللي بعد let إنت اللي بتختاره. وبعد of بتحط المصفوفة.

7 · One more example

It works with numbers too

let scores = [7, 10, 9]; for (let score of scores) { console.log(score + " marks"); }

prints 7 marks, 10 marks, 9 marks

نفس الفكرة مع الأرقام. كل لفة بياخد رقم واحد من scores.

8 · Watch out

A mistake students make

✅ Right

for (let fruit of fruits) { console.log(fruit); }

You already have the value.

❌ Wrong

for (let fruit of fruits) { console.log(fruits[fruit]); }

Here fruit is the value, not a number — so fruits[fruit] is wrong.

في for…of المتغير هو القيمة نفسها، مش رقم الدُرج. اطبعه على طول.

9 · Which one do I use?

A simple rule

📦

Just the values?

Use for…of. Shorter and safer.

🔢

Need the drawer number?

Use the normal for with i.

عايز القيم بس؟ استخدم for…of. محتاج رقم الدُرج كمان؟ استخدم for بالعدّاد.
