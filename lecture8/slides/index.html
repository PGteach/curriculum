Going through an array — for…of

Today: one short loop that visits every value in an array, one by one.

1 · The idea

Think of a box of sweets

You take out one sweet, eat it, then take the next one — until the box is empty. for…of does exactly this with an array.

2 · Remember: arrays

An array is a row of drawers

let fruits = ["apple", "banana", "mango"];
"apple"[0]
"banana"[1]
"mango"[2]

Each value sits in a drawer. The drawer numbers start at 0.

  • What is fruits[1]? — "banana" (the second drawer)
  • What is fruits.length? — 3 (three values)

كل قيمة في دُرج، والترقيم بيبدأ من صفر. فكّر الأول، وبعدين دوس على الإجابة عشان تظهر.

3 · The old way

Printing every fruit with a normal for

for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }

It works — but you must get three things right:

1

Start at 0

let i = 0

2

Stop at the end

i < fruits.length

3

Open the drawer

fruits[i]

بتشتغل، بس لازم تظبط تلات حاجات: تبدأ من صفر، وتقف في الآخر، وتفتح الدُرج بـ fruits[i]. غلطة في أي واحدة = مشكلة.

4 · The easy way

Meet for…of

for (let fruit of fruits) { console.log(fruit); }

Read it as: “for each fruit of fruits, print it.”

No counter. No drawer numbers. It hands you each value, one at a time.

اقراها: «لكل fruit من fruits، اطبعها». من غير عدّاد ولا أرقام أدراج.

6 · Read it part by part

Only three words matter

for (let fruit of fruits) { … }
WordWhat it means
fruita name you choose — it holds one value each time
ofmeans “take from”
fruitsthe array you go through

Tip: name it the singular of the array: pets → pet, names → name.

الاسم اللي بعد let إنت اللي بتختاره. نصيحة: سمّيه مفرد اسم المصفوفة.

9 · Spot the mistake

One of these is wrong. Which one?

Code A

for (let fruit of fruits) { console.log(fruits[fruit]); }

Code B

for (let fruit of fruits) { console.log(fruit); }
  • Which one is wrong? — Code A.
  • Why? — fruit is already the value (like "apple"), not a drawer number. Just print fruit.

في for…of المتغير هو القيمة نفسها، مش رقم الدُرج. اطبعه على طول.

10 · Which loop?

Choose the loop for each job

The jobUse
Print every name in a class listfor…of
Print every mark in a list of marksfor…of
Print the place number next to each name (0 Ali, 1 Mona…)for with i

The rule: only the values? → for…of. Need the drawer number too? → for with i.

عايز القيم بس؟ for…of. محتاج رقم الدُرج كمان؟ for بالعدّاد. جاوب الأول ودوس على الخانة.

Remember these four

What we learned

  • for…of goes through an array and gives you each value, one at a time.
  • Read for (let fruit of fruits) as “for each fruit of fruits”.
  • It runs once for every value, then stops by itself.
  • The variable is the value — print it directly, no [ ].
