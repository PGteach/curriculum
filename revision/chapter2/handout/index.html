2-1 · Cryptographic Technologies and Authentication

Remember. HTTPS uses public-key cryptography to share a key safely and common-key cryptography to move data quickly. Services stay safe by layering encryption, certificates, signatures, and multi-factor authentication.

HTTPS بيستخدم تشفير المفتاح العام عشان يشارك المفتاح بأمان، وتشفير المفتاح المشترك عشان ينقل البيانات بسرعة. والخدمات بتفضل آمنة بالتشفير والشهادات والتوقيعات والمصادقة متعددة العوامل مع بعض.

Exam traps

StatementT / FWhy
HTTPS exchanges all of its data using public-key cryptography.FalsePublic-key only shares the key; common-key moves the data.
Setting two passwords is multi-factor authentication.FalseBoth are knowledge: one factor twice.
A digital certificate verifies that the communication partner is genuine.TrueThat is its job.
A digital signature keeps the content from being read by third parties.FalseThat is encryption; a signature detects tampering.

2-1 · Exam-style question · 6 marks

Explain why HTTPS uses public-key cryptography to share the key and common-key cryptography to exchange the data.

p.37 — Exam-style question [6]

Plan first. Write your points here, then check them against the marking points below. Each point is about one mark.

The marking points

  1. Both sides need the same common key, and sharing it openly is not safe
  2. Public-key cryptography shares the key safely — public key locks, private key unlocks
  3. Public-key cryptography is slow for large amounts of data
  4. Common-key cryptography exchanges large amounts of data quickly
  5. So public-key is used only to share the key, common-key for the data
  6. Result: security and speed together

2-2 · Network Security Design

Remember. Layer your defenses — firewall, VPN, DMZ, endpoints — and verify every access (zero trust). One breach is then far less likely to expose the whole network.

اعمل حمايتك طبقات — جدار حماية، VPN، منطقة معزولة، والأجهزة الطرفية — واتحقق من كل وصول (انعدام الثقة). كده اختراق واحد صعب يكشف الشبكة كلها.

Exam traps

StatementT / FWhy
A VPN automatically deletes files infected with viruses.FalseThat is antivirus software on the endpoints.
A DMZ is mainly there to make communication faster.FalseIt stops an attack on a public server reaching the internal network.
Under zero trust, access from inside the network needs no checking.FalseEvery access is verified, inside or outside.
In defense in depth, if one measure is breached the next can still protect the system.TrueThat is the whole point.

2-2 · Exam-style question · 6 marks

Explain why layering several security measures (defense in depth) protects an organization better than relying on a firewall alone. Refer to what happens if one measure is breached.

p.45 — Exam-style question [6]

Plan first. Write your points here, then check them against the marking points below. Each point is about one mark.

The marking points

  1. A firewall alone is one barrier
  2. If that one barrier is breached, everything inside is exposed
  3. Defense in depth layers several measures
  4. Names at least two layers or measures, e.g. VPN, DMZ, endpoints
  5. If one is breached, the next still protects the system
  6. Conclusion: one breach is much less likely to expose the whole network

2-3 · Incident Response and Risk Management

Remember. Follow the six stages in order (prepare → detect → contain → eradicate → recover → prevent), and prioritize risks by impact × likelihood.

امشي على المراحل الست بالترتيب (تحضير ← اكتشاف ← احتواء ← استئصال ← استعادة ← منع التكرار)، ورتّب المخاطر بالتأثير × الاحتمالية.

Exam traps

StatementT / FWhy
Detection → Eradication → Containment → Recovery is the right order.FalseContainment comes before eradication.
The size of a risk can be judged by impact alone.FalseRisk = impact × likelihood.
All risks must be addressed at the same time.FalseSet priorities: the biggest first.
A software update that adds features is a security incident.FalseNothing was damaged.

2-3 · Exam-style question · 6 marks

Explain why the six stages of incident response must be carried out in order, using recovery and eradication as an example. Refer to what happens if the cause is not removed.

p.51 — Exam-style question [6]

Plan first. Write your points here, then check them against the marking points below. Each point is about one mark.

The marking points

  1. Containment first stops the damage spreading
  2. Eradication removes the cause, e.g. the malware
  3. Recovery returns systems to normal only after that
  4. If recovery comes before eradication, the cause is still there
  5. So the same incident can happen again
  6. Conclusion: order keeps damage small / may need to step back
Prepared by: Mr. Eissa Islam
