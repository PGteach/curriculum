3Answer the following questions.

1. What a VPN is, and two uses

A VPN creates an encrypted virtual private line (a tunnel) over the Internet for safe connection from a remote location. Uses: remote work (connecting from home or while away) and connecting branches (offices in different places).

خط مشفر عبر الإنترنت — للشغل من البيت ولربط الفروع.

2. Why a DMZ is safer

In a DMZ, the public server is separated from the internal network, so if it is attacked the attacker cannot go on to the internal network and its confidential data. Inside the internal network, a hacked public server would give a way straight in.

لو الخادم العام اتخرق، المهاجم ميقدرش يكمل للشبكة الداخلية.

4Explain the technical role of a firewall in monitoring network traffic, and give an example using the protection of databases.

A firewall monitors the traffic at the entry/exit point of a network (it can also sit between parts of a network or on a host) and allows or denies each communication according to rules set in advance. For example, it can allow outside users to reach the public web server but deny any direct access from outside to the database server, so the database is never exposed to the Internet.

جدار الحماية بيقرر: يسمح ولا يمنع، حسب قواعد — ويمنع أي حد من برّه يوصل لقاعدة البيانات مباشرة.

5Explain the concept of a VPN, and show how it protects data sent over public Wi-Fi from eavesdropping.

A VPN is an encrypted virtual private line, or tunnel, created over a public network such as the Internet, so that a remote user can connect safely to an organization's network. On public Wi-Fi other people can try to read the traffic, but with a VPN the content is encrypted inside the tunnel, so an eavesdropper sees only scrambled data. The risk of eavesdropping is therefore reduced.

النفق المشفر بيخلي اللي بيتصنت يشوف بيانات متلخبطة بس.

6Answer the following questions.

1. What a DMZ is and how it protects

A DMZ is an area where servers exposed to the external network (web, mail) are placed separately from the internal network. If one of those servers is attacked, the damage does not reach the internal network.

عزل الخوادم العامة بيحمي اللي جوه.

2. Traditional compared with zero trust

Traditional security trusts users inside the perimeter and checks only at the boundary. Zero trust trusts no one automatically — even inside the network, identity and permissions are verified every time.

التقليدي بيثق في اللي جوه، وانعدام الثقة بيتحقق من الكل كل مرة.

9Explain why layering several security measures (defense in depth) protects an organization better than relying on a firewall alone. Refer to what happens if one measure is breached.

A firewall alone is a single barrier: if it is breached, nothing else stands between the attacker and everything inside the network. Defense in depth layers several measures, each at a different point: a firewall at the network entry, a VPN on the communication path, a DMZ for server placement, and antivirus and updates on the endpoints. If one measure is breached, the next can still protect the system — for example, an attacker who gets into a public web server in the DMZ still cannot reach the internal database. So a single failure is far less likely to expose the whole network.

حاجز واحد لو اتخرق كل حاجة بتتكشف، لكن الطبقات: لو واحدة وقعت، اللي بعدها لسه بتحمي.

10Explain how zero trust verifies every access, based on identity, permissions and context.

Zero trust does not trust any user or device automatically just because it is inside the network or belongs to the organization. Every time a resource is requested, it checks identity (who is asking), permissions (whether they are allowed this resource) and context (whether the request fits — the device, the place, the time), according to the organization's policy. Only then is access given, and the check is repeated for each access.

الهوية، والصلاحيات، والسياق — كل مرة.

11Discuss why the traditional perimeter has become less effective in modern workplaces that rely on cloud computing and remote work.

Traditional security protected a perimeter, on the idea that inside the organization's network is safe and outside is dangerous. With cloud services, data and systems sit outside the office network; with remote work, staff connect from home and from public places. The line between inside and outside has therefore blurred, so a design that protects only the perimeter leaves gaps — which is why zero trust verifies every access instead.

السحابة والشغل من البيت مسحوا الحد بين الداخل والخارج.

12Explain how the firewall, the VPN, the DMZ and endpoint controls fit together to form one defense-in-depth strategy.

Each measure guards a different point. The firewall, at the network entry, allows or denies communication by rules. The VPN protects the communication path by encrypting remote connections. The DMZ governs server placement, keeping public-facing servers apart so an attack on them cannot reach the internal network. Endpoint controls — antivirus and an updated OS — protect each device. Because they are at different points, an attacker who gets past one still faces the next, which is what defense in depth means.

كل إجراء بيحمي نقطة مختلفة — ولو واحد اتعدّى، اللي بعده لسه موجود.

13A hospital moves its patient records to a cloud service and lets doctors access them from home. Using zero trust and defense in depth, suggest two measures it should apply and say where each one helps, then identify one risk that could still remain.

One possible answer. Measure 1 (zero trust): every time a doctor opens a record, their identity and permissions are verified — so being logged in once is not enough. Measure 2 (defense in depth): doctors connect from home through a VPN, so the records cannot be read on the way, and their devices have antivirus and updates. One risk that could remain: a doctor's password could be stolen, or their home computer infected — no design is absolute.

مثال لإجابة: إجراء لكل مفهوم، ومكانه، وخطر لسه موجود.

14Think as an engineer. A company has a public website, staff who work from home, and confidential customer data. List its three assets with the main threat to each, say which defense-in-depth layer matters most for this company and why, and recommend a design with two reasons why layering is safer than a single firewall.

One possible answer. Assets and threats: the public website could be attacked; remote staff could be eavesdropped on; the customer database could be leaked. Most important layer: server placement — putting the website in a DMZ, because it is the most exposed asset and an attack on it must not reach the database. Design: a firewall, a VPN for remote staff, a DMZ for the website, and antivirus and updates on every device, with zero trust checking each access. Two reasons: if one layer is breached the next still protects the system; and each layer covers a different threat that a firewall alone does not.

مثال لإجابة: الأصول والتهديدات، والطبقة الأهم بسبب، وتصميم بسببين.

15Challenge: suggest one measure a small company could add beyond a firewall, and one threat it would still not remove.

One possible answer. Extra measure: a VPN for staff who work from home, so their communication is encrypted. A threat it would still not remove: a member of staff tricked into giving away their password — the VPN protects the connection, not the password.

أي إجراء مناسب، مع تهديد فعلًا هيفضل موجود.

16Reflect: which layer of defense do you think is easiest for an attacker to get past, and why?

One possible answer. The endpoints, because they depend on every user: one person who skips an update or opens an infected file can let an attacker in, however strong the other layers are.

أي طبقة، مع سبب مقنع.
