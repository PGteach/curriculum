4Explain the technical role of a firewall in monitoring network traffic, and give an example using the protection of databases.
Ministry assessments, form A — essay 2
[4 marks]

Model answer. A firewall monitors the traffic at the entry/exit point of a network (it can also sit between parts of a network or on a host) and allows or denies each communication according to rules set in advance. For example, it can allow outside users to reach the public web server but deny any direct access from outside to the database server, so the database is never exposed to the Internet.

The answer must cover:

  • Sits at the network's entry/exit point (or between parts / on a host) (1)
  • Allows or denies communication (1)
  • According to rules set in advance (1)
  • Database example: allow the web server, deny direct external access to the database (1)
5Explain the concept of a VPN, and show how it protects data sent over public Wi-Fi from eavesdropping.
Ministry assessments, form A — essay 3
[4 marks]

Model answer. A VPN is an encrypted virtual private line, or tunnel, created over a public network such as the Internet, so that a remote user can connect safely to an organization's network. On public Wi-Fi other people can try to read the traffic, but with a VPN the content is encrypted inside the tunnel, so an eavesdropper sees only scrambled data. The risk of eavesdropping is therefore reduced.

The answer must cover:

  • Encrypted virtual private line / tunnel over the Internet (1)
  • Lets a remote user connect safely (1)
  • The content is encrypted (1)
  • So an eavesdropper on public Wi-Fi cannot read it (1)

9Explain why layering several security measures (defense in depth) protects an organization better than relying on a firewall alone. Refer to what happens if one measure is breached.
p.45 — Exam-style question [6]
[6 marks]

Model answer. A firewall alone is a single barrier: if it is breached, nothing else stands between the attacker and everything inside the network. Defense in depth layers several measures, each at a different point: a firewall at the network entry, a VPN on the communication path, a DMZ for server placement, and antivirus and updates on the endpoints. If one measure is breached, the next can still protect the system — for example, an attacker who gets into a public web server in the DMZ still cannot reach the internal database. So a single failure is far less likely to expose the whole network.

The answer must cover:

  • A firewall alone is one barrier (1)
  • If that one barrier is breached, everything inside is exposed (1)
  • Defense in depth layers several measures (1)
  • Names at least two layers or measures, e.g. VPN, DMZ, endpoints (1)
  • If one is breached, the next still protects the system (1)
  • Conclusion: one breach is much less likely to expose the whole network (1)

10Explain how zero trust verifies every access, based on identity, permissions and context.
Ministry assessments, form B — essay 3; Arabic book p.40
[4 marks]

Model answer. Zero trust does not trust any user or device automatically just because it is inside the network or belongs to the organization. Every time a resource is requested, it checks identity (who is asking), permissions (whether they are allowed this resource) and context (whether the request fits — the device, the place, the time), according to the organization's policy. Only then is access given, and the check is repeated for each access.

The answer must cover:

  • No automatic trust from being inside the network (1)
  • Identity is checked (1)
  • Permissions are checked (1)
  • Context is checked, every time access is requested (1)
11Discuss why the traditional perimeter has become less effective in modern workplaces that rely on cloud computing and remote work.
Ministry assessments, form B — essay 4; p.43 Point 5(2)
[4 marks]

Model answer. Traditional security protected a perimeter, on the idea that inside the organization's network is safe and outside is dangerous. With cloud services, data and systems sit outside the office network; with remote work, staff connect from home and from public places. The line between inside and outside has therefore blurred, so a design that protects only the perimeter leaves gaps — which is why zero trust verifies every access instead.

The answer must cover:

  • The perimeter idea: inside safe, outside dangerous (1)
  • Cloud services put data and systems outside the network (1)
  • Remote work puts users outside the network (1)
  • So the boundary blurs and perimeter-only protection is not enough (1)
Prepared by: Mr. Eissa Islam
12Explain how the firewall, the VPN, the DMZ and endpoint controls fit together to form one defense-in-depth strategy.
Ministry assessments, form C — essay 2
[6 marks]

Model answer. Each measure guards a different point. The firewall, at the network entry, allows or denies communication by rules. The VPN protects the communication path by encrypting remote connections. The DMZ governs server placement, keeping public-facing servers apart so an attack on them cannot reach the internal network. Endpoint controls — antivirus and an updated OS — protect each device. Because they are at different points, an attacker who gets past one still faces the next, which is what defense in depth means.

The answer must cover:

  • Firewall — network entry, allows/denies by rules (1)
  • VPN — communication path, encrypts remote connections (1)
  • DMZ — server placement, keeps public servers apart (1)
  • Endpoints — antivirus and OS updates on each device (1)
  • Each guards a different point (1)
  • So breaching one still leaves the next — defense in depth (1)
