Part 1 · The role of firewalls

The firewall: rules at the door

Firewall — a system installed at the entry/exit point of a network that allows or denies communication based on rules set in advance.

e.g. Allow access to the web server, but deny direct external access to the database server.

🧱 Firewall rules
→ web serverallow
→ database (from outside)deny
→ web serverallow
→ unknown portdeny

Each request is checked against rules set in advance.كل طلب بيتقارن بقواعد محطوطة مسبقًا.

جدار الحماية: نظام أو برنامج بيراقب حركة مرور الشبكة وبيسمح بيها أو يمنعها حسب قواعد أمنية. ممكن يكون عند حدود الشبكة، أو بين أجزائها، أو على جهاز مضيف. مثال: نسمح بالوصول لخادم الويب ونمنع الوصول الخارجي المباشر لقاعدة البيانات.

Part 2 · VPN (Virtual Private Network)

A private line through a public network

VPN — a technology that creates an encrypted virtual private line (a tunnel) over the Internet, allowing safe connection to a network from a remote location.
Main useWhat it means
Remote workConnecting safely to the organization’s network from home or while away
Connecting branchesConnecting offices in different locations safely

Because the content is encrypted, the risk of eavesdropping is reduced — even on public Wi-Fi.

Safe from home, even on public Wi-Fi.اتصال آمن من البيت، حتى على Wi-Fi عام.

الشبكة الافتراضية الخاصة (VPN): اتصال أو شبكة منطقية خاصة عبر شبكة عامة زي الإنترنت، بتستخدم التشفير وتقنيات النفق عشان تحمي البيانات بين الطرفين. استخداماتها: الشغل عن بُعد، وربط الفروع. ولأن المحتوى متشفّر، مخاطر التنصت بتقل حتى على Wi-Fi عام.

Part 3 · DMZ (Demilitarized Zone)

Keep public servers in their own zone

DMZ — an area where servers exposed to the external network (web servers, mail servers, etc.) are placed separately from the internal network.

If a public-facing server is attacked, damage to the internal network can be prevented.

المنطقة المعزولة (DMZ): منطقة بتتحط فيها الخوادم المعرّضة للشبكة الخارجية — خوادم الويب والبريد — منفصلة عن الشبكة الداخلية. فصلها بيقلل احتمال إن الهجوم يوصل منها للشبكة الداخلية لو واحد منها اتخرق.

Part 4 · Defense in depth

If one layer falls, the next holds

Defense in depth — layering multiple security measures so that, even if one is breached, the next can still protect the system.

الدفاع في العمق: استخدام طبقات كتير من الضوابط الأمنية، بحيث لو طبقة فشلت، الطبقات التانية تقلل الخطر وتحد من أثر الاختراق. الطبقة 1 مدخل الشبكة: جدار الحماية. الطبقة 2 مسار الاتصال: VPN. الطبقة 3 وضع الخوادم: DMZ. الطبقة 4 الأجهزة الطرفية: برنامج مكافحة فيروسات وتحديث نظام التشغيل.

Part 5 · The perimeter

The perimeter has blurred

Perimeter — the old boundary built on the idea that “inside the organization’s network is safe, and outside is dangerous”.

With cloud services and remote work, the line between inside and outside has blurred, and designs that protect only the perimeter are no longer enough.

inside = safe?🏢 office network
☁ cloud services🏠 staff at home📱 phones everywhere

Where is the “inside” now?الداخل بقى فين دلوقتي؟

أمان الشبكات التقليدي اتصمم أساسًا حوالين حماية المحيط الأمني، على أساس إن "جوه شبكة المؤسسة آمن، وبرّه خطر". بس مع انتشار الخدمات السحابية والشغل عن بُعد، الحدود بين "الداخل" و"الخارج" بقت مش واضحة، والتصاميم اللي بتحمي المحيط بس بقت مش كفاية.

5 · Zero trust

Trust nothing automatically

Zero trust — the system does not trust any communication, including from within the organization’s network, and always verifies it.

e.g. Even for access from inside the organization, identity verification and access-permission checks are performed every time.

نهج انعدام الثقة: نهج أمني مش بيدّي ثقة تلقائية لمستخدم أو جهاز لمجرد إنه جوه الشبكة أو ملك المؤسسة. الهوية والصلاحيات والسياق بيتفحصوا عند طلب الوصول للموارد، حسب سياسة المؤسسة.

Exam warning

True or false?

  • Access from within the organization’s network is safe, so verification is unnecessary. — false: zero trust verifies inside access too.
  • A firewall alone is sufficient to protect the network. — false: if it is breached, nothing else stands.
  • A DMZ is provided to improve communication speed. — false: it protects the internal network if a public server is attacked.
  • Only access from outside needs to be monitored. — false: every access is verified.

خلّي بالك، كل الجمل دي غلط: الوصول من جوه آمن فمش محتاج تحقق — غلط. جدار الحماية لوحده كفاية — غلط. الـ DMZ لتحسين السرعة — غلط. نراقب الوصول من برّه بس — غلط.

Think as an engineer

Advise a company on its office network

It has a public website, staff who work from home, and confidential customer data. A firewall only — or a layered design that also verifies every access?

  • Collect data. List the three assets (website, remote staff, customer database) and the main threat to each.
  • Rank the layers. Rank network entry, communication path, server placement and endpoints for this company; justify your top choice.
  • Decide. Recommend a design with two reasons why layering is safer. In pairs, agree on the strongest reason.

Stuck? Start with the most exposed asset — the public website — and place it in a DMZ, so an attack there cannot reach the database.

فكّر كمهندس: شركة بتجهز شبكة مكتبها، عندها موقع عام، وموظفين من البيت، وبيانات عملاء سرية. اذكر الأصول التلاتة والتهديد الرئيسي لكل واحد، واربط كل واحد بطبقة الحماية، وبعدين أوصِ بتصميم بسببين. تلميح: حط الخادم العام في المنطقة المعزولة، ومتعتمدش على العزل لوحده.

Key takeaway · lesson 2-2

Layer your defenses

Hands up again: is a company with a strong firewall safe? What else does it need?

Layer your defenses — firewall, VPN, DMZ, endpoints — and verify every access (zero trust). One breach is then far less likely to expose the whole network.
