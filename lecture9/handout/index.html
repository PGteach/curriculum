Every time you go online

Every time you search on YouTube, buy on Amazon, or open Gmail, you are using a web application — a program you use through your browser, with nothing to install. Behind the simple screen, three tiers work together: the page you interact with, the hidden server that processes the request, and the database that holds all the data. Understanding these three tiers explains how almost every online service is built.

لما بتدوّر في موقع فيديو، أو بتتسوق أونلاين، أو بتستخدم إيميل على الويب، إنت بتستخدم تطبيق ويب، وورا اللي بتشوفه فيه أجزاء مختلفة شغالة مع بعض.

Part 1 · What is a web application?

Web application

An application used through a web browser. It can be used as long as you have a browser, without installing dedicated software. e.g. YouTube, Amazon, Gmail, Google Maps.

تطبيق الويب: تطبيق بيتستخدم عادةً من خلال متصفح الويب، وبعض تطبيقات الويب ممكن كمان تتثبت على الجهاز.

Part 2 · The three tiers of a web application

A web application is broadly composed of three tiers: the frontend, the backend and the database. This is the three-tier architecture.

Prepared by: Mr. Eissa Islam
TierRoleExamples
FrontendThe screen component that users see directly. It runs on the browser and accepts user input.Search screen, product listing pages, input forms
BackendThe server-side processing that users do not see. It processes data and makes decisions.Searching for matching products, login authentication
DatabaseA system that organizes, stores and manages data. It retrieves data when needed and records new data.Product information, user information, order history

الواجهة الأمامية: الجزء اللي بنشوفه ونتعامل معاه في المتصفح. الواجهة الخلفية: بتشتغل على الخادم وبتعالج الطلبات. قاعدة البيانات: بتحفظ البيانات وتوفرها وقت الحاجة.

A way to remember: a restaurant

In a restaurantIn a web application
The waiter: takes your order, brings your plateFrontend — shows and collects
The kitchen you never see: decides and cooksBackend — decides and processes
The storeroom: keeps the food, hands it overDatabase — stores and retrieves

المطعم مثال مننا مش من الكتاب؛ الجمل اللي على اليمين هي جمل الكتاب — احفظها.

True or false?Answer

Part 3 · How the three tiers cooperate

Searching for a product on an online shopping site. A request flows down the tiers, and the reply returns:

StepTierWhat happens
①FrontendReceives the search keywords entered by the user
②FrontendSends the search keywords to the backend
③BackendSearches the database for products that match the criteria
④DatabaseReturns the data of the matching products to the backend
⑤BackendOrganizes the search results and returns them to the frontend
⑥FrontendDisplays the search results on the user’s screen

Pause and think. When you type in a search box and see results, which tier collected your input, and which tier found the answer?

Think as an engineer

A clinic wants a web app where patients book appointments, check free time slots and see past visits. Assign each job to a tier. Diagnose: the booking page opens but no free slots appear. Decide: three tiers or not, with two reasons.

In a new context

A weather app lets users type a city and see the forecast. Which tier takes the city name, looks up the forecast, and stores past forecasts? Name one job the frontend cannot do on its own.

Qureo chapter 31: a function that adds two values, adds three, and compares three. A function is a small machine: it receives values, processes them, and gives a value back.

function name(argumentName) { // processing return result; }
WordMeaning
argumentthe value you pass into the function
return valuethe value the function gives back with return

الدالة زي ماكينة العصير: الوسيط هو اللي بتحطه، والقيمة المرجعة هي اللي بتطلع بـ return.

A function that adds three values

function add3(a, b, c) { return a + b + c; } console.log(add3(2, 4, 6)); // 12 console.log(add3(10, 20, 30)); // 60

نفس الفكرة بتلات وسائط مفصولين بفواصل.

A function that compares three values

function biggest(a, b, c) { let big = a; if (b > big) { big = b; } if (c > big) { big = c; } return big; } console.log(biggest(4, 9, 7));
StepQuestionbig
1let big = a;4
2b > big? 9 > 4 is true9
3c > big? 7 > 9 is falsestays 9
4return bigprints 9

بنبدأ ونقول إن الأولاني هو الأكبر، وبعدين نقارن بـ if — زي المحاضرة 8.

A shortcut: Math.max and Math.min

console.log(Math.max(4, 9, 7)); // 9 console.log(Math.min(4, 9, 7)); // 4

Watch out: no return. If you write a + b; without return, the function gives nothing back and console.log prints undefined — a juice machine with no cup.

من غير return بيطبع undefined.
