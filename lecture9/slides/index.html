Part 1 · What is a web application?

What is a web application?

Web application — an application used through a web browser. You can use it as long as you have a browser, without installing dedicated software.

e.g. YouTube, Amazon, Gmail, Google Maps.

The Arabic book adds: some web applications can also be installed on the device.

▶Video sharingwatch and search
🛒Online shopbuy and pay
✉Web e-mailread and send
🗺Web mapsfind the way

All used through a browser.كلها بنستخدمها من خلال المتصفح.

تطبيق الويب: تطبيق بيتستخدم عادةً من خلال متصفح الويب، وبعض تطبيقات الويب ممكن كمان تتثبت على الجهاز. أمثلة: خدمات الفيديو والتسوق والبريد والخرائط على الويب.

Part 2 · The three tiers of a web application

Three tiers, one application

A web application is broadly built from three tiers: the frontend, the backend and the database. This is called the three-tier architecture.

في النموذج التعليمي ده، بنقسم تطبيق الويب لتلات أجزاء رئيسية: الواجهة الأمامية، والواجهة الخلفية، وقاعدة البيانات — ودي اسمها بنية الطبقات الثلاث.

2 · What each tier does

Who does what?

TierRoleExamples
FrontendThe screen users see directly. It runs on the browser and accepts user input.Search screen, product listing pages, input forms
BackendThe server-side processing users do not see. It processes data and makes decisions.Searching for products that match, login authentication
DatabaseOrganizes, stores and manages data. It retrieves data when needed and records new data.Product information, user information, order history

الواجهة الأمامية: الجزء اللي المستخدم بيشوفه ويتعامل معاه في المتصفح؛ بتعرض المحتوى وبتستقبل اللي بيكتبه. الواجهة الخلفية: الجزء اللي بيشتغل على الخادم، وبيعالج الطلبات ويطبق قواعد التطبيق. قاعدة البيانات: طبقة بتحفظ البيانات وتوفرها وقت الحاجة.

  • The backend is the part that runs on the browser. — false: it runs on the server.
  • A database is a system that organizes, stores and manages data. — true.
  • A web application operates with the frontend alone. — false: it needs all three tiers.

Tap each one to check.

Exam warning

True or false?

  • The frontend has the role of storing and managing data. — false: that is the database.
  • The backend is the part users interact with directly on the browser. — false: that is the frontend.
  • The database has the role of displaying screens to users. — false: the frontend displays.
  • When you search a shop, the backend sends the request to the database. — true: the frontend never asks the database itself.

خلّي بالك: الواجهة الأمامية مش بتخزن البيانات. الواجهة الخلفية مش اللي بنتعامل معاها في المتصفح. قاعدة البيانات مش بتعرض شاشات. واللي بيبعت الطلب لقاعدة البيانات هي الواجهة الخلفية.

Show, decide, store

Hands up again: where are the YouTube videos kept? On your phone — or in a database, reached through the backend?

4 · Remember

A function is a small machine

function name(argumentName) { // processing return result; }
WordMeaning
argumentthe value you pass into the function
return valuethe value the function gives back with return

Like the tiers: receive → process → give back.

🍎In: the argumentsthe values you give it
⚙Inside: the processingthe code between { }
🥤Out: the return valuewhat return sends back

A function is a juice machine.الدالة زي ماكينة العصير.

الدالة زي ماكينة العصير: بتحط فيها فاكهة (الوسيط)، بتشتغل جوّه (المعالجة)، وبتطلّع عصير (القيمة المرجعة) بـ return. ونفس فكرة الطبقات: تستقبل ← تعالج ← ترجّع.

4 · A function that adds three values

Three arguments, one return value

function add3(a, b, c) { return a + b + c; } console.log(add3(2, 4, 6)); console.log(add3(10, 20, 30));
  • The first line prints… — 12 (2 + 4 + 6)
  • The second line prints… — 60 (10 + 20 + 30)
  • How many arguments does add3 take? — three, separated by commas.

نفس الفكرة بتلات وسائط مفصولين بفواصل. فكّر الأول، وبعدين دوس على كل سطر.

4 · A function that compares three values

Which is the biggest?

function biggest(a, b, c) { let big = a; if (b > big) { big = b; } if (c > big) { big = c; } return big;} console.log(biggest(4, 9, 7));

4 · A shortcut you already know

Math.max can take three values

console.log(Math.max(4, 9, 7)); console.log(Math.min(4, 9, 7));
  • Math.max(4, 9, 7) prints… — 9, the same as biggest.
  • Math.min(4, 9, 7) prints… — 4, the smallest.

Qureo chapter 12 used Math.max(A, B) with two values. It works with three too. Writing biggest yourself shows how it decides.

اتعلمنا Math.max و Math.min على قيمتين في الفصل 12، وهما بيشتغلوا على تلاتة كمان. بس لما تكتب biggest بنفسك بتفهم بتقرر إزاي.

4 · Watch out

A function with no return

❌ Forgot return

function add(a, b) { a + b; } console.log(add(3, 5));

✅ With return

function add(a, b) { return a + b; } console.log(add(3, 5));
  • What does the left one print? — undefined: it added, but gave nothing back. A juice machine with no cup.

خلّي بالك: من غير return الدالة بتحسب بس مش بترجّع حاجة، فبيطبع undefined — زي ماكينة عصير من غير كوباية.

Remember these

What we learned

  • A web application is used through a browser.
  • Frontend shows and collects; backend decides and processes; database stores and retrieves.
  • A request flows down the tiers, and the reply comes back up.
  • A function takes arguments, processes them, and gives back a return value — two values, three, or the biggest of three.

تطبيق الويب بيتستخدم من المتصفح • تلات طبقات: تعرض وتجمع، تقرر وتعالج، تخزن وتسترجع • الطلب بينزل والرد بيطلع • الدالة بتاخد وسائط وترجّع قيمة.
