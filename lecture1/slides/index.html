2 · The big difference

Programming or AI?

You want a program that knows if a photo has a cat in it.

Programming

  • You write the rule
  • "If it has pointed ears and whiskers, say cat"
  • Follows your rule exactly, every time
  • Wrong only if your rule was wrong

Artificial Intelligence

  • The computer works out the rule
  • You give it thousands of photos marked cat / not cat
  • Makes its best guess on a new photo
  • Can be wrong — it is guessing

في البرمجة انت اللي بتكتب القاعدة بنفسك. في الذكاء الاصطناعي الكمبيوتر بيستنتج القاعدة من آلاف الأمثلة — وعشان كده ممكن يغلط.

2 · Another way to see it

Recipe vs. watching your mum cook

Programming = a recipe

  • Every step written down, in order
  • Follow it exactly and you get the same dish
  • Miss a step and it fails

AI = learning by watching

  • Nobody wrote the steps for you
  • You watched it done 100 times
  • You cook by feel — sometimes it's off

البرمجة زي وصفة أكل مكتوبة خطوة بخطوة. الذكاء الاصطناعي زي إنك اتعلمت الطبخ بالمشاهدة من غير وصفة — بتطلع حلوة غالبًا، بس ساعات بتغلط.

3 · Two words people mix up

Language vs. code

Programming language

  • The language itself
  • Like English or Arabic
  • Python, JavaScript, C++

Source code

  • An actual sentence written in it
  • The text you type
  • print("hello")

لغة البرمجة زي اللغة العربية نفسها. الكود المصدري زي جملة مكتوبة بالعربي. بايثون هي اللغة، و print("hello") هي الكود.

4 · A programmer's tools

Think of a kitchen

A computer only understands zeros and ones — so we need tools in between.

🔪
The counter

Text editor

Where you write the code. It cannot run it.

🔥
The oven

Compiler

Turns your code into zeros and ones so it can actually run.

🏠
The whole kitchen

IDE

Counter + oven + everything else, in one place.

محرر النصوص هو الطاولة اللي بتجهز عليها. المترجم هو الفرن اللي بيطبخ فعلاً. والـIDE هو المطبخ بالكامل. يعني الـIDE مش أداة رابعة — هو الأدوات دي كلها مجمّعة مع بعض.

4 · Follow one example

You want to print your name

ToolWhat it doesIn this example
Text editor Lets you type and save. Cannot run it. You type print("Eissa") and save
Compiler Translates it into zeros and ones Turns your line into something the processor reads
IDE Editor + compiler + error finder, together You press one button and see Eissa appear

نفس السطر الواحد، شوف كل أداة بتعمل فيه إيه: المحرر بيكتبه ويحفظه، المترجم بيحوّله للغة الآلة، والـIDE بيعمل ده كله بضغطة زرار.
